## Belltower design-sync notes

- Belltower is a vanilla HTML/CSS/JS app (no component framework, no build step
  that produces a `dist/`, no Storybook). It does not fit this skill's normal
  "component library" shape.
- Per explicit user choice (2026-08-28), this project syncs **design tokens
  only** — colors, typography scale, spacing/radius scale, shadows, z-index —
  not reimplemented React components. `componentCount` is intentionally 0.
- The `ds-bundle/` this produces is **hand-built**, not generated by
  `package-build.mjs` (there's no npm package/dist for the converter to
  bundle). It was validated with `package-validate.mjs --no-render-check`
  (no components to render-check).
- Source of truth for tokens:
  - `admin-ui.css` `:root` (top of file) — app-wide tokens: surface/text/
    border colors, `--primary`/`--success`/`--warning`/`--danger`, elevation
    shadows, z-index layers.
  - `carline.css` `:root` and `[data-theme="dark"]` — the `--cl-*` namespace
    used only by the carline/kiosk views, including a full dark theme and a
    `[data-fontsize]` scale toggle.
- Fonts are loaded from Google Fonts CDN, not self-hosted: Inter (primary UI
  font, used by admin-ui.css and carline.css), Fraunces (display font on
  login.html and the carline kiosk header). `styles/fonts.css` in the bundle
  `@import`s the same Google Fonts URLs the app itself uses.
- `index.html` (the public marketing page) uses a third font, Public Sans,
  and its own styling — intentionally excluded from this sync since it's
  not part of the internal-app design language.
- No `_ds_sync.json` anchor was written (this is an off-script layout with
  no `.stories-map.json` manifest for the anchor recipe) — `package-validate.mjs`
  treats this as acceptable (warn, not fail).

### Re-sync risk

- If `admin-ui.css` or `carline.css` token values change, this sync goes
  stale silently — there's no automated diff. Re-run by hand: re-copy both
  files into `ds-bundle/styles/`, re-run `package-validate.mjs --no-render-check`,
  re-upload.
- If Belltower ever migrates to a real component framework with a build,
  this should be redone as a proper "package" or "storybook" shape sync
  instead of this tokens-only hand-built one — see the base SKILL.md.
